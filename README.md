An interactive, high-performance real-time simulation of a spinning black hole accretion disk with Einstein gravitational lensing, relativistic Doppler beaming, gravitational redshift, and dynamic spacetime curvature visualization.

---

## ✨ Features

- **🔭 Relativistic Gravitational Lensing:** Real-time ray bending and Einstein ring deformation around the event horizon shadow.
- **🌀 Relativistic Physics:**
  - Gravitational time dilation and frame-dragging speed boost near the ISCO (Innermost Stable Circular Orbit).
  - Relativistic Doppler shift (blue/redshifting depending on particle velocity vector toward the observer).
  - Gravitational redshift darkening near the photon sphere.
- **🎨 4 Distinct Render Modes:**
  1. **Dot Matrix:** Dynamic particle density rasterization.
  2. **ASCII Terminal:** High-contrast character luminance mapping (`$@B%8&WMX*oahkbdpqwm...`).
  3. **Cyber Matrix:** Katakana and alphanumeric glyph stream.
  4. **Smooth Relativistic:** High-fidelity particle trail rendering with spacetime embedding funnel grid.
- **🌈 Dynamic Color Themes:** Amber Gargantua, Relativistic Cyan, Ultraviolet Amethyst, and Crimson Void.
- **✨ Cosmic Environment:** Multi-layer parallax background stars with arc-stretching lensing and interstellar dust nebulas.

## 🎮 Controls & Interaction

| Control | Action |
| :--- | :--- |
| **Mouse Drag (Hold & Move)** | Orbit 3D camera (Pitch & Yaw rotation) |
| **Mouse Click** | Emit gravitational shockwave ripple + glitch effect |
| **[SPACE]** | Toggle Auto Cycle mode ON / OFF |
| **[ ← ] / [ → ] (Arrow Keys)** | Manually cycle through render modes |
